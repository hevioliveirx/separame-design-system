# SeparaMe · Design System

Design system do **SeparaMe**, aplicativo de gestão financeira para microempresas (ME) do Simples Nacional, com o dia a dia pelo WhatsApp. Trabalho acadêmico em fase de protótipo.

- **Site:** https://hevioliveirx.github.io/separame-design-system/
- **PDF completo:** [`downloads/SeparaMe-Design-System.pdf`](downloads/SeparaMe-Design-System.pdf)
- **Tokens para o Figma:** [`downloads/tokens-studio.json`](downloads/tokens-studio.json), para importar com o plugin Tokens Studio.
- **Tokens para o código:** [`downloads/tokens.css`](downloads/tokens.css), com os modos claro e escuro.
- **Componentes:** `assets/bundle.js` e `assets/bundle.css` (React 18, objeto global `SeparaMe`); tipos em `downloads/index.d.ts`.
- **Logos:** `assets/logos/`. Use sempre sobre o azul-marinho #000B3D.

Fonte: Manrope (Google Fonts, licença OFL). Funcionalidades e valores são hipóteses a validar com usuários.
